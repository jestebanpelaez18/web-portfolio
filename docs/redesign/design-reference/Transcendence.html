Summary

Transcendence is a web platform where people play Pong against each other in real time, join tournaments and manage their profiles. Five of us built it with an Agile workflow, each owning a part of the stack.

I owned the backend: the database schema, the REST APIs, authentication, the real-time game server and the deployment setup.

Highlights

The server runs the game

Ball movement, scoring and player input are handled on the server, so both players always see the same game.

One thread per match

Each active game runs on its own thread with a dedicated asyncio event loop, isolating game state per match.

Auth and privacy

JWT sessions for registration, login and profiles, plus GDPR features such as user anonymization.

Tested APIs

Automated Postman tests for the authentication, matchmaking and gameplay endpoints.

Responsive, but the server decides

The hard part was keeping gameplay responsive while the server stays the authority over the game state.

That took a careful design of the WebSocket events, predictable state transitions on the backend, and strict API validation, so five people working on different layers did not break each other's work.
