Minishell

A Bash-like shell in C, built from scratch.

Grabación de terminal en bucle: un pipe encadenado, una redirección y Ctrl+C

Minishell is a small Unix shell modelled on Bash, written in C under strict constraints: a limited set of library functions and no external libraries.

I led the architectural design, built the pipe logic and hunted bugs across the codebase.

  • ParsingA lexer that handles quotes and environment variable expansion.
  • Pipes and redirectionsChained commands and input, output and append redirections through file descriptors and Unix system calls.
  • Behaves like BashCtrl+C, Ctrl+D and Ctrl+\ handled like Bash, plus command history with the arrow keys. Tested against edge cases with no memory leaks, segfaults or freezes.
