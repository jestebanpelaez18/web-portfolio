summary:
  - "IRC is a text-based chat protocol: clients connect to a server, pick a nickname, join channels and send messages to a channel or to one person. This project is an IRC server written from scratch in C++, tested against irssi as the reference client."
  - "The rules were strict: no forking, every socket non-blocking, and a single poll() call for all reading, writing and new connections. One slow or broken client must never stop the others."
highlights:
