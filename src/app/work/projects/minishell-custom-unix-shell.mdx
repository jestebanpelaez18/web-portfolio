summary:
  - "Minishell is a small Unix shell modelled on Bash and written in C. It reads a command line, works out what it means and runs it: programs found through PATH, pipes between them, redirections, environment variables and the shell's own builtins."
  - "The project had strict rules: only a short list of allowed functions, with GNU Readline for the prompt and history, and everything else written from scratch."
highlights:
  - title: "Quotes and variables"
    text: "The tokenizer and expander handle single and double quotes, $VAR expansion and $? for the last exit status, following Bash's rules for which quotes expand."
  - title: "Pipes and redirections"
    text: "Commands are chained with pipes through file descriptors, with input, output, append and heredoc (<<) redirections."
  - title: "Builtins in the right place"
    text: "cd, export, unset and exit run inside the shell itself, because they change its state. Other commands run in a child process with fork and execve."
  - title: "Behaves like Bash"
    text: "Ctrl+C, Ctrl+D and Ctrl+\\ behave as in Bash, syntax errors are reported without crashing, and the shell runs with no memory leaks, segfaults or freezes."
